# athx

Shared training and nutrition journal for ATHX New York 2027.

The app lives in [`athx-tracker/`](athx-tracker/). Its
[README](athx-tracker/README.md) covers what it does, how to run it locally,
how the full-workout scenario is calculated, and how to get it onto a phone.

Built on the vinext Sites starter: a Next.js app that builds to a Cloudflare
Worker, with Cloudflare D1 for storage and Sign in with ChatGPT for access.
